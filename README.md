
# CriminalIntent — Android Application

## Overview
CriminalIntent is an Android application developed using Kotlin
and Android Studio.

The application allows users to create, view, edit, and delete
crime records.

## Technologies
- Kotlin
- Android Studio
- Android SDK
- XML Layouts
- RecyclerView
- Fragments
- MVVM Architecture
- Room Database
- SQLite
- Kotlin Coroutines
- Git and GitHub

## Implemented Features
- Display crime records
- Create new crime records
- Edit existing records
- Delete records
- Navigate between list and detail screens
- Manage application data through ViewModels
